- **Sync (optional):** Never twice can share the posts you read between browsers and computers through a small server of your own, so a post read in one place stays out of the others. Off unless you add a `sync.json` (see the README). The server sees post ids and when they were read, nothing else.

To update a zip install, download `subfeed-for-x-0.7.0.zip` below and load it in place of the old folder. A git clone updates with `git pull`.
