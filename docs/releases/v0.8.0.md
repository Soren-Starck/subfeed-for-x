- **Minimalist removes ads and suggestions:** promoted posts, "Who to follow", "Discover more" under a post and X's Premium prompts are taken out of every timeline X loads (Home, a post's replies, profiles, search) before X draws them.
- **Following, newest first:** with Minimalist on, Following always asks X for the most recent posts, even if it was set to Popular, and For you comes back empty if X ever loads it.
- **Explore is a search box:** its tabs, trends and news are hidden. Grok buttons on posts and Premium upgrade buttons are hidden everywhere.
- **Phone layout:** in a narrow window Home's tab row shows only Following (X put those tabs in its top bar, where 0.7 did not look), the bottom bar keeps Home, Search and Notifications, and the menu behind your picture loses Premium, Communities and the like.

To update a zip install, download `subfeed-for-x-0.8.0.zip` below and load it in place of the old folder. A git clone updates with `git pull`.
